Procure AI

Natural-language procurement analytics with secure, company-scoped data access.

Python · FastAPI · MCP · PostgreSQLBackend systems · AI tools · Guardrails
Overview

Procure AI lets users ask natural-language questions about procurement data and receive useful, company-scoped answers. The challenge was making the conversational surface feel flexible without giving the model unrestricted access to internal data or database operations.

Decisions I owned +

I implemented MCP-backed tools and the chat orchestration layer, then added role and company context to every query path. Read-only SQL enforcement, structured response handling, and sanitized logging made the boundaries explicit instead of leaving them to a prompt.

The system also handles unresolved or invalid requests gracefully, keeping the assistant inside the procurement domain.

Technical shape +

FastAPI routes feed testable prompt builders and tool-calling orchestration backed by PostgreSQL and SQLAlchemy. Isolated read-only connection pools and tenant-aware access context protect the data path.

What changed +

The result is an AI product with a defined domain, controlled operations, and a clearer story for both users and the engineers responsible for it.
